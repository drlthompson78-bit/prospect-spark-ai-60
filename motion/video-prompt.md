```

reference image (round cake, white fondant base with pastel pink drip top, upside-down waffle

Second half: the existing visible layers of the SAME cake separate vertically into a clean,
elegant exploded-view composition — top tier with the cone rising, cream layer, cake layer,
base with the drip — each layer floating in a clear vertical stack, still centered and readable.

This must be ONE continuous uninterrupted shot: no cuts, no scene changes, no montage, no
jump cuts, no stitched angles. It must feel like one seamless camera move around the same cake
in the same environment.

Critical consistency rule: do NOT add any ingredients or decorations that are not already
visible in the reference cake. Do not invent extra layers, extra decorations, extra cones or
extra candy. The second half only separates the existing visible layers. The cake must keep
the same decoration count, visual identity, colors and proportions from start to finish.

Style: bright premium food commercial, warm daylight, soft studio background, realistic sugar
and fondant textures, subtle floating sprinkles as minimal accents, shallow depth of field but
keep the cake readable. Keep enough light negative space around the cake for website text
overlay.

Restrictions: no text, no logos, no hands, no people, no fast cuts, no camera shake, no chaotic
explosion, no messy particles. Duration 8-12 seconds.
```
